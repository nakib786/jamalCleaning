What changed: the brand green `#00a650` is only 3.2:1 against white, so small white text on it failed WCAG AA. `global.css`
now has `--color-primary-strong` (`#008744`, 4.6:1) for surfaces that carry small white text (`.btn`, active project filter,
service sidebar link, step number badges, the "100% Satisfaction Guarantee" card, skip link) and for active menu links on
white, and `--color-primary-heading` (`#009b4a`) for the two-tone headline accent on light backgrounds (the accent stays
the bright green on dark backgrounds). Other fixes: "Learn More" on About is now "Explore Our Services"; phone/WhatsApp/email
links have 24 px tap targets; the project previous/next labels are `text-body` instead of the 2.6:1 light grey; the
testimonial slider uses valid carousel markup; the decorative marquee is `aria-hidden`.

Tried and dropped: `build.inlineStylesheets: "always"` made no measurable LCP difference on `/services/` (scores 90–98 across runs).

## Notes / gotchas

- REA runs as its own MCP server from scripts (`tools/lib/rea.ts`); to use REA tools directly in Claude Code run
  `npx rea-agents setup` and restart. REA warns that Node ≥ 24.22.1 is recommended (this machine has 24.14.0; it still works).
- The REA source clone used for docs is in the session scratchpad (temporary; safe to delete).
- An orphaned crawl process from before the scope change may still be running; stop it with
  `taskkill /PID 3492 /T /F` if it is (it only crawls excluded blog pages).
- Logo: the supplied PNG's wordmark is dark navy; `tools/assets/brand.ts` generates a white-wordmark version for dark
  backgrounds. Replace `src/assets/brand/logo.png` and re-run it to change the logo everywhere.
- Screenshots: `--hide-scrollbars` in the capture Chrome widens the layout by 5px versus the reference (1435px), which can change
  line wraps; launch it without that flag for verification. Scroll with wheel events (not rapid `scrollTo`) before full-page
  captures, otherwise Lenis fights the scripted scroll and some reveals never fire.
- **Placeholder content to replace before launch** (copied from the demo): testimonial names/quotes, "Ratings 4.5" and
  "586k Clients globally", the home counters, project fact sheets ("Themeforest, Evanto", "Main Address, USA") and the
  lorem-ipsum project text, and the service detail text (it mentions interior design).
- Social links are placeholders in `src/config/site.ts`, so the top bar shows the phone number instead until they are set.
