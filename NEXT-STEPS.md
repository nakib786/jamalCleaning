## Notes / gotchas

- REA runs as its own MCP server from scripts (`tools/lib/rea.ts`); to use REA tools directly in Claude Code run
  `npx rea-agents setup` and restart. REA warns that Node ≥ 24.22.1 is recommended (this machine has 24.14.0; it still works).
- The REA source clone used for docs is in the session scratchpad (temporary; safe to delete).
- An orphaned crawl process from before the scope change may still be running; stop it with
  `taskkill /PID 3492 /T /F` if it is (it only crawls excluded blog pages).
- Logo: the supplied PNG's wordmark is dark navy; `tools/assets/brand.ts` generates a white-wordmark version for dark
  backgrounds. Replace `src/assets/brand/logo.png` and re-run it to change the logo everywhere.
- Social links are placeholders in `src/config/site.ts`, so the top bar shows the phone number instead until they are set.
